# Contributing

This is a guide, not a program, so contributions are corrections. If a step didn't work for you, a link landed wrong, or a word wasn't defined, open an issue at [github.com/morriss-group/ai-for-appliance-repair/issues](https://github.com/morriss-group/ai-for-appliance-repair/issues) and say which page and what happened. A pull request is welcome for the same things; keep it to the page you read. Everything published here follows [PUBLIC-IDENTITY.md](PUBLIC-IDENTITY.md): no customer data, no credentials, no roadmap language, and `scripts/gate.sh` runs on every push.
